# 🎲 Ludo Classic — Android

A native, fully offline Ludo game for Android by **Harsh Nagar**.

## Features

- 🎮 4-player Ludo: You + 3 computer opponents
- 🎲 Random dice rolls
- 🟢🟡🔵🔴 Four colored players with 4 tokens each
- ⭐ Safe squares
- 💥 Token capture
- 🏠 Home lanes and exact finish
- 🔁 Extra turn on a six
- 🤖 Offline computer opponents
- 🏆 Win screen and restart
- 📱 Portrait Android UI
- 🌐 No internet connection required at runtime

## Tech

- Kotlin
- Android SDK
- Custom Canvas-based game board
- Minimum Android API 23

## Build

Open the project in Android Studio and build the `app` module.

For a local Gradle setup with Gradle available:

```bash
gradle assembleDebug
```

The debug APK will be generated under `app/build/outputs/apk/debug/`.
